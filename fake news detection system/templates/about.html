About This Project

🎯 Project Overview

In today's digital era, the rapid growth of social media and online news platforms has made it easier to spread misinformation and fake news. This Fake News Detection System uses advanced Machine Learning and Natural Language Processing (NLP) techniques to automatically identify whether a given news article is genuine or fake.

🔬 How It Works

  1. Data Collection: News data is collected from both reliable and unreliable sources to create a diverse training dataset.
  2. Text Preprocessing: The system removes stop words, performs tokenization, and applies lemmatization to clean and normalize the text.
  3. Feature Extraction: Text is converted into numerical features using TF-IDF (Term Frequency-Inverse Document Frequency) vectorization with n-grams.
  4. Model Training: Multiple supervised learning algorithms are trained and compared:
    • Logistic Regression
    • Naive Bayes (Multinomial)
    • Support Vector Machine (SVM)
  5. Prediction: The best-performing model analyzes linguistic and contextual patterns to classify news articles as real or fake with a confidence score.

💻 Technology Stack

Backend: Python, Flask,SQL Lite
ML Libraries: Scikit-learn, NLTK
NLP: TF-IDF, Tokenization, Lemmatization
Frontend: HTML, CSS, JavaScript

🎓 Educational Purpose

This is a mini-project designed to demonstrate the application of Machine Learning and NLP in combating misinformation. It serves as an educational tool to understand:

  • Text preprocessing and feature engineering
  • Supervised learning classification algorithms
  • Model comparison and evaluation metrics
  • Building ML-powered web applications
  • Real-world applications of AI in social good

⚠️ Disclaimer

While this system uses advanced machine learning techniques, it should not be the sole source for verifying news authenticity. Always cross-reference with multiple reliable sources and use critical thinking when evaluating news content. This tool is designed as an educational project and a supplementary verification aid.
